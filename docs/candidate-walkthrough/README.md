# Business guide

Read [Business terms](business_terms.md) for the entities, roles, and actions. Then read [Canonical business rules](canonical_business_rules.md) for module invariants, domain policies, and transitions, followed by intermodule workflows. The specification includes LaTeX equations and linked SVG diagrams; editable Graphviz sources sit beside each SVG.

These documents describe operating conventions version **2026-10-26.1**. The CRM records physical returns directly, unlocks points proportionally to qualifying cash, and keeps cancellation advances as unapplied cash unless Accounts explicitly reserves credit. Correction operations have the scope defined in the guide.
